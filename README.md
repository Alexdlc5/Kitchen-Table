# Kitchen Table

Classic American card games for iPhone and iPad: Spades and Hearts at launch, Euchre next. Hearts free forever, one $6.99
unlock for the rest, no ads ever, no subscriptions, no accounts, no server. A provably fair deal, partners built from real
review complaints, Comfort mode, Game Center family tables.

Capacitor web app on the Glimmerwood stack (Alexdlc5/shardgrid, `docs/NEW_GAME_PLAYBOOK.md`).

- `docs/DESIGN.md`: games, screens, flow, product rules, Comfort mode, caregiver screen, fair deal, house rules, family tables
- `docs/AI_SPEC.md`: every partner/opponent sin from the reviews as a test
- `docs/PLAYER_RESEARCH.md`: 1,000 incumbent reviews, P0/P1/P2, do-not-do list
- `docs/TABLE.md`: the look
- `docs/SETUP.md`: the owner's steps and status
